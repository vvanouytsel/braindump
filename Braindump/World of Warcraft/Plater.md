Plater is an addon that adds nameplates in World of Warcraft.

# Quazii profile

[Quazii](https://quazii.com/) provides an excellent baseline plater profile. However I did some changes to make it more personal. Since updating the profile often removes all customized settings, here is a writeup of the things I have changed.

## Settings

* General settings
	* Health Bar Texture: You Are Beatifull!
* Enemy Npc
	* Change all fonts to Expressway
	* Npc Name Text
		* Use font 9
		* Change X Offset to 11
	* Spell Name Text
		* Use font 9
	* Change X Offset for Npc Name Text to 11
	* Use font 8 for Spell Cast Time Text
	* Use font 8 for Health Information and change Y offset to 11
	* Set Shadow Color to black

## Mods

* Smart Name Shortener
	* Disable Abbreviate names (W.O. Warcraft)
* Import [Border Color Manager](https://wago.io/_aQRhsLRu) and set to white
* Enable Quazii Interrupt CD Indicator
	* Set 'Default Border Color' to green
